\begin{abstract}
\AbsFonts
Optimising inside a learned world model entangles finite-sample selection luck with model exploitation. In Micropolis, a spatial-economic simulator with bit-exact replay, we benchmark planning error above finite-sample selection luck by running each optimiser identically inside a learned world model and inside an exact-simulator reference on fresh seeds. Across a \Ladder-checkpoint model ladder that clears short-horizon fidelity gates yet drifts over our \Horizon-month horizon, excess false acceptance appears before search and persists across budgets. Under cross-entropy search, world-model ground-truth pass rates stall between \Bp{3} and \Bp{4} plans while exact-simulator discovery keeps climbing, widening the absolute shortfall from \PaTenShort{} to \PaTenThouShort{}\AbsReplanClause. In-imagination PPO policies trained for \RlMonths{} imagined months show parallel optimism, and perturbation-controlled patching isolates post-earthquake fire spread as a causal driver on recovery. Within this ladder (\AcPairs{} model-task pairs), trajectory-fidelity metrics show weak association with PPO exploitation, whereas single-plan verdict calibration on one logged plan per starting instance achieves Spearman \AcEOneRho{} (\AcEOneWithin{} within family). Single-seed fiscal-coverage retraining cuts planning excess without raising ground-truth pass rates, while post-hoc inference defences reduce false acceptance only by rejecting many truly passing plans. Extending primary one-step training sixfold on a single seed (\ExtTrEpochs{} epochs) raises held-out likelihood yet worsens \Horizon-month spatial drift, flipping miscalibration from optimistic false acceptance to pessimistic rejection.
\end{abstract}
